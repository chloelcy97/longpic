# 长图

把长文排成图片发微博，自动分页。纯前端，零依赖。

<https://chloelcy97.github.io/longpic/>

## 为什么是 1080 × 2240 起

微博的图片压缩规则：

| 条件 | 结果 |
|---|---|
| 宽高都 ≤ 1080 | 尺寸不变 |
| 宽高都 > 1080，宽高比 ≤ 2 | 长边等比压到 1080 |
| 宽高都 > 1080，宽高比 > 2 | 短边等比压到 1080 |
| 一边 > 1080、一边 < 1080，宽高比 > 2 | 尺寸不变 |
| 以上任一档，文件 > 500KB | 转 70% 质量 JPG |

所以出图固定 1080 宽、高度不低于 2240（宽高比 2.07），落在「尺寸不变」里。
高度没有上限，只受 5MB 单张限制。PNG 超过 500KB 时自动改存高质量 JPG。

上传时选「原图」。

## 用法

1. 填标题，正文粘进去，空一行分段。
2. 右侧实时出图，每张标了体积和格式。
3. 下载全部。手机上长按图片保存。

## 选项

| | |
|---|---|
| 版式 | 朱线 / 刊头 / 大字 |
| 字体 | 黑体 / 宋体 |
| 字号 | 36 / 41 / 47（按 1080 宽计） |
| 留白 | 紧凑 / 适中 / 舒展（行距、段距、边距联动） |
| 每张长度 | 2240 / 4000 / 6400 |
| 分段 | 首行缩进 / 空行 |
| 落款 | 页脚左侧，刊头版在题头右上 |

设置和草稿存在浏览器 localStorage。

## 排版

- 两端对齐
- 标点悬挂，避头尾
- 段首不落孤行，段尾不落寡行
- 分页先定每页容量再定页高，各张疏密一致

## 本地运行

```bash
python3 -m http.server 5199
```

或直接打开 `index.html`。

## 部署

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `(root)`。
仓库内的 `.nojekyll` 使 Pages 跳过 Jekyll 处理。
