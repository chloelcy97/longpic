# 长图 · 长微博排版

把一段长文排成几张干净的图，直接发微博。

微博的压缩规则是这样的：一边超过 1080、另一边不到 1080，**且宽高比大于 2**，
就原样保留；否则把长边等比压到 1080。所以 1080×1440 会被压成 810×1080，
字缩掉两成半，看着就糊 —— 长图反而是安全的那一档。

这里出图一律 1080 宽、高度至少 2240（宽高比 2.07），正好落在「不动」里。
剩下只有体积：单张超过 500KB 会被转成 70% 质量的 JPG，所以每张图上面标了 KB，
超了会变红。

在线用：<https://你的用户名.github.io/longpic/>

零构建。一个 html、一个 css、一个 js，打开就能跑。

---

## 怎么用

1. 填标题，正文粘进去，空一行分段。
2. 右边实时出图，几张的长短一致、疏密也一致。
3. 「下载全部」，一张张存下来。手机上长按图片也能存。

发微博的时候记得选「原图」，不然还是会被压。

## 能调的

| | |
|---|---|
| 版式 | 刊头 / 双线 / 大字 / 竖题，四种标题排法 |
| 字体 | 宋体 / 黑体 |
| 字号 | 小 36 · 中 41 · 大 47（按 1080 宽算，手机上看正好） |
| 每张长度 | 短 2240 · 标准 3200 · 长 4400（都在安全线以上，选长的分页就少）|
| 分段 | 首行缩进 / 空行 |
| 落款 | 页脚左边（刊头版在题头右上），页码在右 |

设置和草稿都存在这台设备的浏览器里，关掉再开还在。

## 排版细节

- 两端对齐，右边是齐的。
- 标点悬挂：句号逗号跟着上一行走，不会孤零零掉到下一行开头。
- 开引号、开括号不留在行尾。
- 段首不落单行，段尾不落寡行 —— 该翻页就整段翻。
- 几张的疏密是匀开的：先定每张装多少，再定页高，不会第一张塞满、最后一张剩两行。
- 白底，末页正文收尾处点一个小菱形。

## 本地跑

```bash
python3 -m http.server 5199
```

打开 <http://localhost:5199> 。或者直接双击 `index.html` 也行。

## 放到 GitHub Pages

推上去，仓库 Settings → Pages → 选 main 分支根目录。仓库里的 `.nojekyll`
是告诉 Pages 别拿 Jekyll 处理，原样发出去就好。
